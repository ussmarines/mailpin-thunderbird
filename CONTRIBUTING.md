# Contribution

1. Lire `AGENTS.md` et `docs/ARCHITECTURE.md`.
2. Créer une branche courte et ciblée.
3. Ajouter un test ou une garde pour chaque correction.
4. Exécuter `npm run ci`.
5. Décrire précisément les tests Thunderbird réels effectués.
6. Ne jamais joindre de profil Thunderbird, message, adresse privée, base SQLite utilisateur ou secret.

Toute contribution est soumise à la clause **Contributions** de `LICENSE` et doit pouvoir être intégrée, modifiée, distribuée et relicenciée par le propriétaire dans MailPin. Une contribution n’accorde aucun droit de redistribution ou d’exploitation du reste du projet. N’ajoutez pas de code dont la licence est incompatible ou inconnue.
