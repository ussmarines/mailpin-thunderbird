# Glossary

**About:3pane** — Thunderbird's internal three-pane mail UI where MailPerch injects its panel and row controls.

**Agenda** — Optional calendar/task integration behind a capability-aware adapter.

**Experiment** — Privileged `pinInbox` API implementation that bridges extension pages to Thunderbird internals and local storage.

**Guided** — Persisted settings value presented to users as Recommended.

**PinCompatibility** — Facade that groups Messages, Tags and Agenda adapters.

**Pinned reference** — Local metadata record that identifies a message/conversation and its workflow state without storing the body.

**Provider matrix** — Local snapshot of account/calendar capabilities and compatibility observations.

**Stable key** — MailPerch's internal durable identifier for a pinned reference.

**State data** — Logical JSON storage for UI and saved-view state alongside SQLite tables.

**Strong identity** — Gmail thread, root Message-ID, Thunderbird thread ID, or a conversation key derived from those identifiers.

**XPI** — Installable Thunderbird extension archive.
