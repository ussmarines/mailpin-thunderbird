# Project background

## Contexte

MailPerch est une MailExtension Thunderbird MV3 locale. Son panneau d'épingles complète la liste native sans en modifier les compteurs.

Sources canoniques :

- `PROJECT_MEMORY.md`
- `docs/ARCHITECTURE.md`
- `AGENTS.md`

## Frontières durables

- aucune donnée ni ressource runtime distante ;
- les corps de messages et pièces jointes ne sont jamais stockés ;
- les décisions détaillées sont dans les pages liées.
