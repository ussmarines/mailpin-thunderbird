# Limites connues — MailPin

## Source 1.7.13 / release publique 1.7.12

La source candidate 1.7.13 déclare Thunderbird 153.0 à 160.* mais **le runtime Thunderbird 160.0 n'a pas encore été validé**. Ne pas affirmer que le panneau fonctionne sur Thunderbird 160 avant un smoke réel sur la candidate exacte. Voir `../VALIDATION_REPORT_1.7.13.md`.

La release publique 1.7.12 couvre Thunderbird 153.0 à 159.*, avec QA Linux/Windows, CodeQL et smoke réel Linux 159.0 PASS (voir `../VALIDATION_REPORT_1.7.12.md`). Les fournisseurs réseau, calendriers distants, macOS, l’accessibilité assistée et l’identité binaire inter-OS restent des validations distinctes. L’Experiment impose toujours une revue ATN indépendante.
