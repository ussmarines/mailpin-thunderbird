# Spécification d’interface

## Panneau

- placé au-dessus de la liste native ;
- repliable ;
- limité en hauteur avec défilement interne ;
- portée et tri explicites ;
- compteurs d’épingles uniquement dans le panneau ;
- aucune modification du badge du dossier à gauche.

## Cartes

- liseré de couleur du compte ;
- expéditeur, date, objet et métadonnées lisibles ;
- punaise pleine colorée ;
- cinq actions rapides maximum ;
- menu complet au clic droit ou via le bouton « Plus » ;
- clic simple : affichage à droite sans défilement de la liste ;
- double-clic : ouverture native.

## Menu contextuel

- doit rester dans le viewport ;
- clavier : flèches, Début, Fin, Échap, Entrée/Espace natifs des boutons ;
- fermeture au clic extérieur, scroll, resize, blur et changement de dossier ;
- confirmation avant suppression si activée.

## Dashboard

- thème clair/sombre ;
- état de chargement ;
- message d’erreur réessayable ;
- liste, Kanban, affaires, historique ;
- pas de HTML brut non stylé ;
- mise en page utilisable à largeur réduite.
